# Micro-Internship Platform

A web-based Micro-Internship Platform that connects students with short-term, task-based internships designed to build skills, provide real-world experience, and empower both learners and mentors.

This project includes task-first selection, skill-matching score*, and reflection-based certification — features not typically found on standard internship portals.

---

 📌 Features

🧠 Core Functionality
- Student Login & Registration
- Mentor / Company Login & Registration
- Admin Dashboard
- Micro-Internship Listings
- Apply & Submit Work
- Task Preview & Sample Assignment
- Skill Matching Score
- Reflection-Based Certification
- Mentor Feedback & Ratings
- User Profiles & Progress Tracking

---

## 🚀 Unique Value

This platform stands out from other internship sites because of:

1. ⭐ Task-First Selection
   - Students complete a small sample task before formal selection — removes resume bias.

2. 💡 Skill Matching Score
   - Students see a match percentage between their skills and internship requirements.

3. 📝 Reflection Based Certification
   - Final certificates are issued only after students submit a short reflective summary of their learning.
